# نسخه v0.5.2 — اصلاح Hover آیکون و چیدمان معرفی مرکز

## هدف نسخه

اصلاح استایل کارت‌های سامانه و هدینگ معرفی مرکز بر اساس بازخورد UI، بدون تغییر ساختار داده یا Schema تنظیمات.

## تغییرات کارت‌های سامانه

- قانون ویژه‌ی `.ba-jihadi-center__system-card:first-child` به‌طور کامل حذف شد تا کارت اول استایل مرزی متفاوت نداشته باشد.
- `fill` اجباری از selector پایه‌ی `.ba-jihadi-center__system-icon svg` حذف شد.
- کنترل Elementor با شناسه `system_icon_color` دیگر `fill` تولید نمی‌کند و فقط `color` را برای SVG و Font Icon تنظیم می‌کند.
- کنترل جدید `system_icon_hover_color` به بخش Style ویجت اضافه شد.
- رنگ آیکون در Hover و `focus-visible` کارت لینک‌دار تغییر می‌کند و مقدار پیش‌فرض آن با رنگ Hover عنوان هماهنگ است.
- برای تغییر نرم رنگ، transition روی `color` آیکون‌های SVG و Font Icon اضافه شد.
- Selector رنگ Hover عنوان نیز `focus-visible` را پوشش می‌دهد تا رفتار کیبورد با Hover ماوس یکسان باشد.

> نکته: برای SVG، تغییر رنگ زمانی اعمال می‌شود که فایل SVG از `currentColor` استفاده کند. قالب دیگر روی خود عنصر SVG مقدار `fill` تحمیل نمی‌کند.

## تغییرات معرفی مرکز

برای `.ba-jihadi-center__intro-head` مقادیر زیر به استایل پایه اضافه شد:

```css
margin-right: auto;
margin-left: auto;
text-align: center;
```

`max-width` و `margin-bottom` قبلی حفظ شده‌اند.
