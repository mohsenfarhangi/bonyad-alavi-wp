# نسخه v0.6.4 — صورتحساب-only در پرداخت سریع مشارکت

## هدف

ساده‌سازی Quick Checkout صفحه مشارکت مردمی با نمایش صرفاً فیلدهای صورتحساب و جلوگیری از به‌هم‌ریختگی عرض فیلدهای WooCommerce در قالب‌های مختلف.

## تغییرات

- رندر Checkout Inline فقط از گروه `billing` در `WC_Checkout::get_checkout_fields()` انجام می‌شود.
- گروه‌های `shipping`، `account` و `order` در فرم پرداخت سریع نمایش داده نمی‌شوند.
- اعتبارسنجی Required و Validatorها نیز فقط روی فیلدهای Billing اجرا می‌شود تا هیچ فیلد مخفی Shipping موجب خطا نشود.
- Terms/Privacy استاندارد WooCommerce مستقل از گروه فیلدها حفظ شده‌اند.
- Grid فیلدهای پرداخت سریع تک‌ستونه شده و عرض `.form-row`ها با `width: 100% !important` و `max-width: 100% !important` و حذف Float اجباری شده است.
- Override عرض به `bap__donation-form` Scope شده و به سایر فرم‌های WooCommerce سایت نشت نمی‌کند.

## فایل‌های تغییرکرده

- `inc/woocommerce/class-ba-participation-quick-checkout-service.php`
- `assets/css/bonyad-alavi-participation-widget.css`
- `docs/handoff.md`
- `docs/versions/v0.6.4.md`

## نکات مهاجرت

- Migration دیتابیس لازم نیست.
- تنظیمات Gateway و Orderهای قبلی تغییری نمی‌کنند.
- اگر افزونه‌ای فیلد سفارشی را داخل گروه Billing اضافه کند، همچنان خودکار در Quick Checkout نمایش داده می‌شود.

## تست‌ها

- `php -l` روی تمام فایل‌های PHP قالب.
- `node --check` روی تمام فایل‌های JavaScript قالب.
- بررسی عدم وجود رندر/Validation گروه Shipping در Quick Checkout.
- بررسی Scope و `!important` عرض Form Row.
- تست سلامت ZIP کامل و Patch.
