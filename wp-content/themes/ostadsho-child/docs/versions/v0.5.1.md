# نسخه v0.5.1 — انتخاب دوحالته رسانه کارت‌های سامانه

## هدف نسخه

یکسان‌سازی تجربه انتخاب رسانه در کارت‌های `ba-jihadi-center__system-icon` با سکشن همراهان مرکز و تفکیک صریح دو حالت «تصویر» و «آیکون/SVG» در داشبورد و Elementor.

## تغییرات رابط مدیریت

Repeater کارت‌های سامانه در تب «مرکز حرکت‌های مردمی و جهادی» اکنون از Switcher مشترک انتخاب رسانه استفاده می‌کند:

- حالت **تصویر**: فقط تصویر غیر SVG انتخاب می‌شود و در فرانت با `<img>` رندر می‌شود.
- حالت **آیکون / SVG**: فقط فایل SVG در داشبورد انتخاب می‌شود و در فرانت به‌صورت Inline `<svg>` رندر می‌شود.

منطق Switcher داشبورد بین کارت‌های سامانه و همراهان تکرار نشده و از Helper داخلی مشترک `BA_Center_Settings_Tab::render_repeater_media_switcher()` استفاده می‌کند.

## تغییرات Elementor

Repeater کارت‌های سامانه اکنون مانند همراهان دارای این کنترل‌هاست:

- `use_svg` برای انتخاب حالت رسانه.
- `image` از نوع `Controls_Manager::MEDIA` در حالت تصویر.
- `icon` از نوع `Controls_Manager::ICONS` در حالت آیکون/SVG.

تعریف این سه کنترل بین Repeater کارت‌های سامانه و همراهان با متد مشترک `add_repeater_media_choice_controls()` انجام می‌شود.

در حالت SVG آپلودی، فایل به‌صورت Inline SVG رندر می‌شود. آیکون‌های کتابخانه‌ای Elementor نیز از `Icons_Manager` عبور می‌کنند تا با قرارداد رسمی Elementor و قابلیت Font Icon SVG نسخه‌های جدید سازگار بمانند.

## ساختار داده کارت سامانه

ساختار جدید داشبورد:

```php
array(
    'media_type' => 'image', // image | svg
    'image_id'   => 123,
    'svg_id'     => 0,
    'title'      => 'عنوان کارت',
    'url'        => 'https://example.com',
)
```

دو شناسه `image_id` و `svg_id` همزمان فعال نیستند و Service هنگام Sanitize مقدار نامرتبط را صفر می‌کند.

## سازگاری با نسخه‌های قبل

فیلد قدیمی `icon_id` حذف فوری نشده و فقط در `BA_Center_Settings_Service::normalize_system_card_media()` به‌عنوان مسیر Migration خوانده می‌شود:

- اگر MIME فایل `image/svg+xml` باشد → `svg_id`.
- در غیر این صورت → `image_id`.

بعد از ذخیره مجدد تنظیمات، ساختار جدید ذخیره می‌شود و Migration دیتابیس جداگانه لازم نیست.

داده قدیمی Elementor که آیکون آن قبلاً با Media Control ذخیره شده نیز در Resolver به حالت Image منتقل می‌شود تا خروجی قبلی از بین نرود.

## رندر امن SVG

Helper مشترک زیر به `BA_Media_Helper` اضافه شد:

`BA_Media_Helper::get_inline_svg_attachment()`

این متد:

- فقط Attachment با MIME نوع SVG را می‌پذیرد.
- فایل را از مسیر Attachment می‌خواند.
- XML declaration و DOCTYPE را حذف می‌کند.
- SVG را با Allowlist محدود `wp_kses()` پاک‌سازی می‌کند.
- خروجی Inline با `aria-hidden` و `focusable=false` برمی‌گرداند.

این Helper باید برای نیازهای آینده‌ی رندر Inline فایل SVG استفاده شود و کد خواندن/پاک‌سازی SVG در Featureها تکرار نشود.
