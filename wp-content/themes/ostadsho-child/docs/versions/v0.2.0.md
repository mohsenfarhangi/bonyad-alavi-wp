# نسخه 0.2.0 — کاروسل تصاویر محصول و ویجت Loop

## نوع تغییر

قابلیت جدید سازگار با ساختار موجود (MINOR).

## هدف

یکپارچه‌کردن منبع تصاویر پروژه‌های مشارکت مردمی با رسانه‌های واقعی محصول ووکامرس و اضافه‌کردن یک ویجت سبک و مستقل برای نمایش تصویر/کاروسل محصول داخل Loopهای المنتور.

## تغییرات ویجت «صفحه مشارکت مردمی»

- کنترل دستی `project_image` از پنل ویجت حذف شد.
- منبع تصویر اصلی فقط خود محصول ووکامرس است.
- ترتیب تصاویر به‌صورت ثابت زیر است:
  1. تصویر شاخص محصول.
  2. تصاویر Product Gallery به ترتیب ثبت‌شده در ووکامرس.
- اگر Product Gallery محصول دارای تصویر باشد و حداقل دو تصویر قابل نمایش وجود داشته باشد، بخش تصویر اصلی به کاروسل تبدیل می‌شود.
- فلش قبلی و بعدی در دو سمت تصویر قرار گرفته‌اند.
- کاروسل با کلیک، کلیدهای جهت‌دار و Swipe لمسی قابل کنترل است.
- اگر محصول گالری نداشته باشد، تصویر شاخص به‌صورت ثابت نمایش داده می‌شود.
- اگر محصول هیچ تصویری نداشته باشد، Placeholder ووکامرس نمایش داده می‌شود و Lightbox برای Placeholder فعال نمی‌شود.
- دکمه `bap__zoom` در محصول دارای گالری از آیکون ذره‌بین به آیکون گالری تغییر می‌کند.
- Lightbox فقط تصاویر واقعی محصول را نمایش می‌دهد و تصویر دستی Elementor دیگر وارد آن نمی‌شود.
- با بازکردن Lightbox، اگر کاربر قبلاً در کاروسل اصلی حرکت کرده باشد، Lightbox از همان تصویر فعال شروع می‌شود.

## ویجت جدید «تصویر محصول (کاروسل)»

شناسه Elementor:

```text
bonyad_alavi_product_gallery
```

کاربرد اصلی این ویجت، استفاده داخل Loop Itemهای محصولات المنتور است.

### تنظیمات محتوا

- **فعال‌سازی کاروسل**: روشن/خاموش.
- **حداکثر تعداد تصاویر**: فقط در حالت کاروسل نمایش داده می‌شود.
  - مقدار `0` یعنی همه تصاویر.
  - محدودیت روی کل خروجی اعمال می‌شود؛ بنابراین تصویر شاخص نیز جزو تعداد محسوب می‌شود.
- **اندازه فایل تصویر**: Thumbnail، Medium، Medium Large، Large یا Full.

### رفتار در حالت کاروسل خاموش

- فقط اولین تصویر موجود محصول نمایش داده می‌شود.
- اولویت با تصویر شاخص است.
- اگر تصویر شاخص وجود نداشته باشد، اولین تصویر گالری استفاده می‌شود.
- هیچ دکمه Gallery یا Lightbox در این ویجت وجود ندارد.

### تنظیمات ظاهری

- نسبت تصویر: `1:1`، `4:3`، `3:2` و `16:9`.
- نحوه قرارگیری تصویر: `cover` یا `contain`.
- گردی گوشه‌ها.
- اندازه فلش‌های کاروسل.

## معماری و تصمیمات فنی

### `BA_Product_Media_Service`

یک Service مشترک برای خواندن Context محصول و ساخت مجموعه تصاویر ایجاد شد. این سرویس باعث می‌شود ویجت اصلی و ویجت Loop منطق WooCommerce Gallery را دوباره پیاده‌سازی نکنند.

برای Loop المنتور، `get_the_ID()` قبل از global product بررسی می‌شود تا هر Loop Item رسانه محصول مربوط به همان رکورد را دریافت کند.

### `BA_Media_Helper`

رندر تصویر، alt تصویر و SVGهای مشترک ناوبری/گالری در Helper مستقل قرار گرفتند. بنابراین کدهای تکراری رندر Attachment بین ویجت اصلی، Lightbox و ویجت Loop حذف شدند.

### `BAProductCarousel`

یک هسته JavaScript مشترک برای حرکت کاروسل ایجاد شد. این کلاس با selectorهای BEM هر ویجت پیکربندی می‌شود و مسئول موارد زیر است:

- قبلی/بعدی.
- گردش حلقه‌ای اسلایدها.
- کلیدهای جهت‌دار.
- Swipe لمسی.
- مدیریت `aria-hidden`.
- آزادسازی Event Listenerها هنگام Destroy شدن ویجت Elementor.

### Bootstrap المنتور

فایل `inc/elementor/elementor-widgets.php` از توابع procedural به دو مسئولیت شی‌گرا تفکیک شد:

- `BA_Elementor_Assets`: ثبت Assetها.
- `BA_Elementor_Widgets_Registrar`: ثبت دسته و ویجت‌ها.

این تفکیک برای رعایت Single Responsibility انجام شده است.

## استاندارد BEM

UI جدید ویجت Loop زیر Block اختصاصی زیر scope شده است:

```text
.ba-product-gallery
```

نمونه Elementها و Modifierها:

```text
.ba-product-gallery__viewport
.ba-product-gallery__slide
.ba-product-gallery__slide--active
.ba-product-gallery__nav
.ba-product-gallery__nav--prev
.ba-product-gallery--carousel
.ba-product-gallery--static
```

کاروسل جدید داخل ویجت مشارکت نیز از ساختار BEM موجود Block `bap` استفاده می‌کند:

```text
.bap__media-carousel
.bap__media-slide
.bap__media-slide--active
.bap__media-nav
.bap__media-nav--prev
.bap__media-nav--next
.bap__zoom--gallery
```

## نکات مهاجرت

- مقدار قدیمی `project_image` ممکن است هنوز داخل تنظیمات ذخیره‌شده Elementor وجود داشته باشد، اما از نسخه 0.2.0 دیگر خوانده یا نمایش داده نمی‌شود.
- برای تعیین تصویر صفحه مشارکت باید از **Product Image** و **Product Gallery** خود ووکامرس استفاده شود.
- هیچ تغییری در دیتابیس برای مهاجرت لازم نیست.

## تست و کنترل کیفیت

- Syntax تمام فایل‌های PHP قالب با `php -l` بررسی شد.
- Syntax تمام فایل‌های JavaScript با `node --check` بررسی شد.
- توازن Blockهای CSS برای فایل‌های CSS قالب بررسی شد.
- بررسی شد که هیچ Reference اجرایی به `project_image` در سورس باقی نمانده باشد.
- بررسی شد Assetهای ویجت جدید تنها از طریق Dependencyهای Elementor بارگذاری شوند و enqueue سراسری نشوند.
- Patch نسبت به baseline نسخه 0.1.0 ساخته می‌شود.

## مواردی که عمداً در این نسخه تغییر نکردند

- Refactor عمومی `functions.php` و enqueue تکراری Checkout که در نسخه 0.1.0 ثبت شده بود، خارج از Scope این قابلیت باقی ماند.
- منطق Lightbox موجود به‌جز منبع تصاویر و شروع از اسلاید فعال، تغییر رفتاری دیگری نکرد.
