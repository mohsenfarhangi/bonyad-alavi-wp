# نسخه v0.5.5 — کنترل‌های ریسپانسیو آمار و Hero

## هدف نسخه

این نسخه کنترل‌های استایل Elementor برای بخش آمار و Hero ویجت «مرکز حرکت‌های مردمی و جهادی» را تکمیل می‌کند تا تنظیم فاصله پنل آمار و نحوه نمایش تصویر Hero بدون CSS دستی قابل انجام باشد.

## تغییرات

### 1. Margin کامل پنل آمار

برای `.ba-jihadi-center__stats-wrap` کنترل ریسپانسیو `stats_margin` از نوع `DIMENSIONS` اضافه شد.

- چهار جهت بالا، راست، پایین و چپ قابل تنظیم هستند.
- واحدهای `px`، `%`، `em` و `rem` پشتیبانی می‌شوند.
- کنترل قدیمی `stats_margin_top` برای حفظ سازگاری تنظیمات موجود باقی مانده است.
- در صورت مقداردهی `stats_margin`، مقدار چهارجهته جدید بر Margin قبلی اولویت CSS خواهد داشت.

### 2. ارتفاع ریسپانسیو Hero

کنترل `hero_min_height` تکمیل و با عنوان «ارتفاع Hero» نمایش داده می‌شود.

مقادیر پیش‌فرض:

- Desktop: `600px`
- Tablet: `540px`
- Mobile: `480px`

ارتفاع همچنان به صورت `min-height` اعمال می‌شود تا در صورت افزایش محتوای Hero، محتوا بریده نشود.

همچنین Rule قدیمی موبایل که `480px` را مستقیماً روی `.ba-jihadi-center__hero` و `.ba-jihadi-center__hero-inner` اعمال می‌کرد حذف شد. ارتفاع اکنون از متغیر `--ba-jc-hero-height` و کنترل ریسپانسیو Elementor پیروی می‌کند.

### 3. استایل تصویر Hero

کنترل‌های زیر به بخش Style > Hero اضافه شدند:

- نحوه نمایش تصویر (`object-fit`): Cover، Contain، Fill، None و Scale Down
- موقعیت ریسپانسیو تصویر (`object-position`) در ۹ موقعیت متداول
- شفافیت ریسپانسیو تصویر
- CSS Filters استاندارد Elementor برای Brightness، Contrast، Saturation، Blur و Hue

این کنترل‌ها مستقیماً روی `.ba-jihadi-center__hero-image` اعمال می‌شوند.

## سازگاری

- مقدار قبلی `hero_image_position` همچنان معتبر است؛ مقدار Legacy مانند `center` نیز CSS معتبر تولید می‌کند.
- `stats_margin_top` حذف نشده است تا نمونه‌های موجود Elementor بدون تغییر ناگهانی ظاهر باقی بمانند.
- این نسخه تغییری در محتوای داشبورد، Queryها یا قرارداد اولویت تنظیمات ایجاد نمی‌کند.
