# نسخه v0.5.3 — Lazy Rendering و Fade-in سکشن‌های مرکز

## هدف نسخه

بهینه‌سازی رندر فرانت‌اند ویجت «مرکز حرکت‌های مردمی و جهادی» و نمایش تدریجی سکشن‌ها هنگام ورود به viewport، بدون مخفی‌کردن دائمی محتوا در صورت خطای JavaScript.

## رفتار جدید

- Hero هنگام ورود اولیه به viewport با Fade-in نمایش داده می‌شود، اما به دلیل اهمیت LCP به‌صورت eager باقی می‌ماند و `content-visibility` روی آن فعال نیست.
- سکشن‌های آمار، معرفی، اخبار، چندرسانه‌ای، همراهان و FAQ با Modifier مشترک `ba-jihadi-center__viewport-section--lazy` علامت‌گذاری شده‌اند.
- برای سکشن‌های پایین صفحه از `content-visibility: auto` و `contain-intrinsic-size` استفاده می‌شود تا مرورگر Layout/Paint محتوای خارج از viewport را تا نزدیک‌شدن کاربر به تعویق بیندازد.
- `IntersectionObserver` فقط یک بار برای هر سکشن اجرا می‌شود و هنگام ورود سکشن به viewport یک Fade-in با Web Animations API ایجاد می‌کند.
- اگر `IntersectionObserver` یا Web Animations API در دسترس نباشد، محتوا بدون مخفی‌شدن و بدون وابستگی شکننده به JavaScript نمایش داده می‌شود.
- در حالت `prefers-reduced-motion: reduce` انیمیشن غیرفعال است.
- در Elementor Editor، Lazy Rendering غیرفعال می‌شود تا سکشن‌ها همیشه قابل انتخاب و ویرایش باشند.

## قرارداد BEM و Behavior Hook

کلاس‌های مشترک:

```text
ba-jihadi-center__viewport-section
ba-jihadi-center__viewport-section--lazy
ba-jihadi-center__viewport-section--visible
```

Behavior Hookها:

```text
data-ba-jc-reveal
data-ba-jc-lazy-section
data-ba-jc-revealed
```

Hookهای `data-*` فقط برای JavaScript هستند و استایل Feature همچنان با BEM scope می‌شود.

## نکات عملکردی

- تصاویر Hero همچنان eager و دارای `fetchpriority="high"` هستند؛ Lazy کردن Hero به‌صورت عمدی انجام نشده تا LCP آسیب نبیند.
- تصاویر محتوایی اخبار، چندرسانه‌ای، همراهان و تصاویر System Card که از قبل `loading="lazy"` داشتند، همان رفتار را حفظ می‌کنند.
- Lazy Section در این نسخه به معنی defer کردن Render/Layout/Paint در مرورگر است؛ Queryهای PHP همچنان در سمت سرور هنگام ساخت صفحه اجرا می‌شوند.
