# نسخه v0.5.9 — کنترل استایل عنوان و تاریخ اخبار و چندرسانه‌ای

## هدف

تکمیل کنترل‌های Style ویجت مرکز برای مدیریت مستقل تایپوگرافی و رنگ عنوان و تاریخ مطالب در سکشن‌های اخبار/مقالات و چندرسانه‌ای، با پشتیبانی از حالت عادی و Hover/Focus.

## تغییرات

- برای خبر/مقاله شاخص، تایپوگرافی مستقل عنوان و تاریخ در Elementor در دسترس است.
- برای سایر اخبار/مقالات، تایپوگرافی مستقل عنوان و تاریخ در Elementor در دسترس است.
- برای آیتم شاخص چندرسانه‌ای، تایپوگرافی مستقل عنوان و تاریخ اضافه شد.
- برای سایر آیتم‌های چندرسانه‌ای، تایپوگرافی مستقل عنوان و تاریخ اضافه شد.
- هر چهار گروه دارای تب‌های «عادی» و «هاور» برای انتخاب جداگانه رنگ عنوان و تاریخ هستند.
- حالت `focus-visible` همان رنگ Hover را دریافت می‌کند تا ناوبری کیبورد رفتار بصری یکسانی داشته باشد.
- تاریخ آیتم شاخص چندرسانه‌ای به Markup اضافه شد تا کنترل تاریخ برای آیتم اول نیز خروجی واقعی داشته باشد.
- Transition رنگ عنوان‌ها و تاریخ‌ها در CSS پایه اضافه شد.
- Helper خصوصی `register_post_item_text_style_controls()` ایجاد شد تا قرارداد Typography/Normal/Hover بین اخبار و چندرسانه‌ای تکرار نشود.
- شناسه کنترل‌های Typography عنوان قبلی حفظ شده‌اند تا تنظیمات ذخیره‌شده Elementor از نسخه‌های قبل از بین نروند.

Migration داده لازم نیست. کنترل‌های Typography عنوان با همان شناسه‌های نسخه قبل ثبت می‌شوند و فقط کنترل‌های تاریخ و رنگ‌های Normal/Hover به آن‌ها افزوده شده‌اند.
