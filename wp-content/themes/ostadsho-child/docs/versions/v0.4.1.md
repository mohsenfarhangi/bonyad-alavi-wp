# نسخه v0.4.1 — اصلاح لینک و آیکون کارت‌های سامانه

## هدف نسخه

رفع دو Regression در بخش کارت‌های سامانه (`ba-jihadi-center__system-card`):

1. لینک واردشده در Repeater Elementor به دلیل Override کامل Repeater داشبورد به خروجی نهایی نمی‌رسید.
2. کنترل آیکون Elementor از نوع `MEDIA` بود و آیکون‌های استاندارد Icon Library المنتور به‌درستی Render نمی‌شدند.

## اصلاح قرارداد اولویت کارت‌های سامانه

برای `system_cards` اولویت داشبورد به‌صورت فیلدبه‌فیلد اعمال می‌شود:

- عنوان غیرخالی داشبورد بر عنوان Elementor اولویت دارد.
- لینک غیرخالی داشبورد بر لینک Elementor اولویت دارد.
- رسانه/آیکون معتبر داشبورد بر آیکون Elementor اولویت دارد.
- اگر لینک یا آیکون داشبورد خالی باشد، مقدار همان فیلد از Elementor استفاده می‌شود.

این Resolve فقط در `BA_Center_Settings_Service` انجام می‌شود و ویجت منطق Merge جداگانه ندارد.

این رفتار عمداً برای Repeater کارت‌های سامانه است، چون عنوان‌های پیش‌فرض داشبورد نباید باعث حذف لینک یا آیکون تنظیم‌شده در Elementor شوند.

## آیکون Elementor

کنترل `icon` در Repeater کارت‌های سامانه از `Controls_Manager::MEDIA` به `Controls_Manager::ICONS` تغییر کرد.

رندر از API رسمی Elementor انجام می‌شود:

```php
Icons_Manager::render_icon( $icon, array( 'aria-hidden' => 'true' ) );
```

برای داده‌های قدیمی که قبلاً با Media Control ذخیره شده‌اند، fallback روی `icon[url]` حفظ شده است تا ارتقا باعث حذف ناگهانی تصویر قبلی نشود.

رسانه انتخاب‌شده از داشبورد همچنان با Attachment ID وردپرس Render می‌شود.

## استایل آیکون

برای آیکون‌های استاندارد Elementor پشتیبانی CSS برای هر دو خروجی زیر اضافه شد:

- `<i>` برای Font Iconها
- `<svg>` برای SVG Iconها

در بخش Style ویجت نیز کنترل‌های زیر تفکیک شدند:

- اندازه باکس آیکون
- اندازه خود آیکون
- رنگ آیکون
- پس‌زمینه آیکون
- گردی باکس آیکون

تمام Selectorها زیر Block `ba-jihadi-center` باقی مانده‌اند.

## تست‌ها

- `php -l` روی تمام فایل‌های PHP قالب.
- `node --check` روی تمام JavaScriptهای قالب.
- تست Resolver برای fallback لینک Elementor وقتی لینک داشبورد خالی است.
- تست Resolver برای fallback آیکون Elementor وقتی آیکون داشبورد خالی است.
- تست اولویت لینک و آیکون داشبورد وقتی مقدار معتبر دارند.
- بررسی وجود `Controls_Manager::ICONS` و `Icons_Manager::render_icon()` برای کارت سامانه.
- بررسی سلامت ZIP کامل و Patch.
