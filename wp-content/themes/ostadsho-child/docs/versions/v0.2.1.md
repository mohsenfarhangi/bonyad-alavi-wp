# نسخه 0.2.1 — بهینه‌سازی Lazy Load کاروسل تصویر محصول

## نوع تغییر

اصلاح کوچک و بهینه‌سازی عملکرد بدون تغییر قرارداد ویجت (PATCH).

## هدف

جلوگیری از Lazy Load شدن تصویر اولیه کاروسل محصول و به‌تعویق‌انداختن بارگذاری تصاویر غیرقابل مشاهده‌ی بعدی برای بهبود نمایش اولیه Loopهای المنتور.

## تغییر انجام‌شده

در ویجت «تصویر محصول (کاروسل)» با شناسه `bonyad_alavi_product_gallery` رفتار بارگذاری تصاویر به شکل زیر اصلاح شد:

- وقتی کاروسل واقعاً فعال است و بیش از یک تصویر وجود دارد:
  - تصویر اول با `loading="eager"` رندر می‌شود.
  - تصویر دوم و تمام تصاویر بعدی با `loading="lazy"` رندر می‌شوند.
- وقتی کاروسل غیرفعال است یا فقط یک تصویر برای محصول وجود دارد، رفتار قبلی حفظ می‌شود و تصویر تکی با `loading="lazy"` رندر می‌شود.
- `decoding="async"` برای تمام تصاویر حفظ شده است.

## دلیل فنی

تصویر اول محتوای قابل مشاهده‌ی اولیه‌ی کارت Loop است و نباید به دلیل Lazy Load با تأخیر ظاهر شود. تصاویر بعدی تا زمان جابه‌جایی کاربر در کاروسل قابل مشاهده نیستند و Lazy Load برای آن‌ها باعث کاهش درخواست‌های اولیه و مصرف پهنای باند می‌شود.

## تست و کنترل کیفیت

- Syntax فایل PHP ویجت با `php -l` بررسی شد.
- بررسی شد شرط Lazy Load فقط بر اساس وضعیت واقعی `$is_carousel` اعمال شود، نه صرفاً روشن بودن کنترل Elementor.
- رفتار حالت تک‌تصویر بدون تغییر باقی مانده است.
