# نسخه v0.6.5 — اصلاح راه‌اندازی فیلدهای Checkout Inline

## هدف

رفع خطای JavaScript `Cannot read properties of undefined (reading 'find')` هنگام آماده‌سازی Quick Checkout در صفحه مشارکت مردمی.

## علت خطا

در نسخه‌های قبلی پس از تزریق فیلدهای صورتحساب، Eventهای داخلی WooCommerce یعنی `country_to_state_changing`، `country_to_state_changed` و `updated_checkout` بدون آرگومان‌های مورد انتظار به‌صورت دستی Trigger می‌شدند. Handler مربوط به Country/State برای این Eventها wrapper/context دریافت می‌کند و در نبود آن روی مقدار `undefined` متد `.find()` اجرا می‌شد.

## تغییرات

- حذف Trigger دستی `country_to_state_changing`.
- حذف Trigger دستی `country_to_state_changed`.
- حذف Trigger دستی `updated_checkout` از مرحله Initialize فرم Inline.
- حفظ `wc-enhanced-select-init` برای فیلدهای تازه تزریق‌شده.
- Trigger کردن `change` واقعی فقط روی فیلدهای `billing_country` / `.country_to_state` داخل همان `bap__quick-checkout`.
- اجازه به `country-select.js` ووکامرس برای تولید Eventهای داخلی با wrapper و country صحیح.
- محدود ماندن initialization به DOM همان Quick Checkout برای جلوگیری از اثر جانبی روی فرم‌های دیگر صفحه.
