# نسخه v0.3.1 — کامپوننت عمومی Repeater مدیریت

## هدف نسخه

حذف پیاده‌سازی‌های تکراری Repeater در رابط مدیریت قالب و تبدیل Repeater قدیمی FAQ محصول به یک Component عمومی و قابل استفاده مجدد.

این نسخه یک **PATCH** است زیرا قرارداد داده‌های ذخیره‌شده و خروجی فرانت را تغییر نمی‌دهد و تمرکز آن روی Refactor داخلی و نگهداری بهتر کد است.

## تغییرات اصلی

### ۱. ایجاد `BA_Admin_Repeater_Component`

کلاس جدید در مسیر زیر ایجاد شد:

`inc/admin/components/class-ba-admin-repeater-component.php`

مسئولیت‌ها:

- Wrapper استاندارد BEM
- Template ردیف جدید
- Index ردیف‌ها
- Add / Remove
- Move Up / Move Down
- Empty State
- Assetهای عمومی
- ساخت نام استاندارد فیلدهای تو در تو با `field_name()`
- انتشار رویداد `ba:admin-repeater:change`

### ۲. Asset عمومی Repeater

فایل‌های جدید:

- `assets/css/ba-admin-repeater.css`
- `assets/js/ba-admin-repeater.js`

Block عمومی UI:

`ba-admin-repeater`

منطق Add/Remove/Move دیگر نباید در JavaScript هر Feature تکرار شود.

### ۳. Refactor متاباکس FAQ محصول

فایل `inc/woocommerce/product-faq-metabox.php` از ساختار procedural به کلاس زیر منتقل شد:

`BA_Product_FAQ_Metabox`

تغییر قرارداد ذخیره داده انجام نشده است و Meta Key زیر حفظ شده:

`_bap_product_faqs`

بنابراین داده‌های FAQ موجود محصولات بدون Migration قابل استفاده هستند.

Repeater این متاباکس اکنون از `BA_Admin_Repeater_Component` استفاده می‌کند.

فایل JavaScript اختصاصی قدیمی حذف شد:

`assets/js/bonyad-alavi-product-faq-admin.js`

ظاهر اختصاصی فیلدهای FAQ محصول در Block زیر قرار گرفت:

`ba-product-faq-admin`

و فایل جدید زیر اضافه شد:

`assets/css/bonyad-alavi-product-faq-admin.css`

### ۴. مهاجرت Repeaterهای تنظیمات مرکز

تمام Repeaterهای سفارشی تب مرکز به Component عمومی منتقل شدند:

- `stats`
- `system_cards`
- `partners`
- `faqs`

`BA_Center_Settings_Tab` فقط فیلدهای اختصاصی هر ردیف را رندر می‌کند و مدیریت چرخه Repeater را به Component واگذار می‌کند.

### ۵. حذف منطق تکراری JavaScript

منطق زیر از `assets/js/ba-center-settings.js` حذف شد:

- محاسبه Index
- افزودن ردیف
- حذف ردیف
- مدیریت Template

این فایل اکنون فقط رفتار اختصاصی تنظیمات مرکز را نگه می‌دارد:

- Media Picker
- حذف رسانه
- Switcher تصویر/SVG همراهان

### ۶. Helper نام فیلد

متد زیر برای تولید نام ورودی‌های تو در تو اضافه شد:

```php
BA_Admin_Repeater_Component::field_name();
```

این متد برای Repeaterهای Settings و FAQ محصول استفاده می‌شود تا رشته‌های نام‌گذاری در چند محل تکرار نشوند.

## مستندات Component

راهنمای کامل استفاده در فایل زیر اضافه شد:

`docs/components/admin-repeater.md`

این راهنما شامل:

- محدوده استفاده
- API
- نمونه Settings API
- نمونه نام فیلد
- Context
- رویداد JavaScript
- قرارداد Sanitize
- قوانین توسعه آینده

است.

## نکته درباره Elementor

این Component فقط برای UI سفارشی `wp-admin` است. Repeaterهای داخل Elementor باید همچنان از API رسمی `Elementor\Repeater` استفاده کنند و مهاجرت آن‌ها به این Component صحیح نیست.

## سازگاری داده

هیچ نام Option، Meta Key یا ساختار داده ذخیره‌شده تغییر نکرده است. در نتیجه Migration دیتابیس نیاز نیست.

## تست‌ها

- `php -l` روی تمام فایل‌های PHP قالب.
- `node --check` روی تمام JavaScriptهای قالب.
- بررسی حذف selector/data-attributeهای Repeater قدیمی.
- بررسی اینکه FAQ محصول و هر چهار Repeater تنظیمات مرکز از `BA_Admin_Repeater_Component::render()` استفاده می‌کنند.
- بررسی باقی‌ماندن Repeaterهای Elementor روی API رسمی `Elementor\Repeater`.
- بررسی سلامت ZIP کامل و Patch.
