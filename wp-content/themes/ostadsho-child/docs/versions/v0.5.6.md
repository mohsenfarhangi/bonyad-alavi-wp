# نسخه v0.5.6 — اصلاح Object Fit تصویر Hero

## هدف

اصلاح ساختار ابعادی تصویر Hero ویجت «مرکز حرکت‌های مردمی و جهادی» تا کنترل‌های `object-fit` و `object-position` Elementor در تمام حالت‌ها به‌درستی عمل کنند.

## تغییرات

- `.ba-jihadi-center__hero-media` اکنون به‌صورت صریح `width: 100%` و `height: 100%` دارد.
- برای جلوگیری از خروج تصویر از محدوده Hero، روی Media Container مقدار `overflow: hidden` اعمال شده است.
- `.ba-jihadi-center__hero-image` با `position: absolute` و `inset: 0` کل فضای Media Container را پوشش می‌دهد.
- خود تصویر به‌صورت صریح `width: 100%` و `height: 100%` دارد.
- `max-width: none` و `max-height: none` اضافه شده تا محدودیت‌های عمومی قالب/WordPress روی تصویر Hero اثر نگذارند.
- کنترل‌های موجود Elementor برای `object-fit` و `object-position` بدون تغییر API ادامه پیدا می‌کنند.

## سازگاری

هیچ تنظیم ذخیره‌شده‌ای تغییر نکرده و Migration داده لازم نیست. این نسخه فقط ساختار CSS تصویر Hero را اصلاح می‌کند.

## بررسی‌ها

- بررسی وجود `width:100%` و `height:100%` روی Media Container و Hero Image.
- بررسی باقی‌ماندن کنترل‌های `object-fit` و `object-position` Elementor.
- بررسی Syntax تمام PHP و JavaScriptهای قالب.
- تست سلامت ZIP کامل و Patch.
