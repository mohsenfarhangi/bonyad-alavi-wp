# نسخه v0.3.0 — ویجت مرکز حرکت‌های مردمی و جهادی

## هدف نسخه

تبدیل طرح تأییدشده صفحه «مرکز هماهنگی حرکت‌های مردمی و جهادی» به یک ویجت مستقل Elementor، با حفظ هویت بصری طرح، BEM کامل، Queryهای پویا و یک تب مدیریتی جدید در «تنظیمات بنیاد علوی».

این نسخه یک **MINOR** محسوب می‌شود زیرا قابلیت جدیدی به قالب اضافه می‌کند و قرارداد نسخه‌های قبلی را نمی‌شکند.

## قابلیت‌های اضافه‌شده

### ۱. تب جدید تنظیمات مرکز

تب «مرکز حرکت‌های مردمی و جهادی» به سیستم تب‌دار موجود در تنظیمات بنیاد علوی اضافه شد.

فیلدهای داشبورد:

- عنوان Hero با مقدار پیش‌فرض «مرکز هماهنگی حرکت های مردمی و جهادی».
- متن و لینک دکمه ثبت‌نام Hero.
- تصویر پس‌زمینه Hero.
- عنوان و زیرعنوان پنل آمار.
- Repeater نامحدود آمار شامل عدد، عنوان و زیرعنوان.
- چهار آمار پیش‌فرض مطابق طرح تأییدشده.
- عنوان و توضیحات معرفی مرکز؛ توضیحات با ویرایشگر استاندارد وردپرس.
- Repeater کارت‌های مرکز شامل آیکون/تصویر یا SVG، عنوان و لینک.
- Kicker، عنوان و زیرعنوان همراهان مرکز.
- Repeater همراهان با Switcher انحصاری «تصویر / SVG»، عنوان اختیاری و لینک اختیاری.
- Kicker، عنوان و زیرعنوان FAQ.
- Repeater پرسش و پاسخ FAQ.

### ۲. اولویت تنظیمات داشبورد

قرارداد اولویت به شکل زیر است:

- عنوان Hero، متن/لینک دکمه، آمار، معرفی مرکز و کارت‌های سامانه از داشبورد خوانده می‌شوند.
- تصویر Hero ابتدا از داشبورد خوانده می‌شود؛ اگر خالی باشد تصویر Elementor و در نهایت تصویر پیش‌فرض بسته قالب استفاده می‌شود.
- Kicker/عنوان/زیرعنوان همراهان و FAQ در صورت غیرخالی بودن از داشبورد اولویت می‌گیرند.
- اگر حداقل یک Partner معتبر در داشبورد وجود داشته باشد، Repeater همراهان Elementor به‌طور کامل نادیده گرفته می‌شود.
- اگر حداقل یک FAQ معتبر در داشبورد وجود داشته باشد، Repeater FAQ در Elementor به‌طور کامل نادیده گرفته می‌شود.

### ۳. ویجت Elementor جدید

ویجت با نام فنی زیر ثبت شد:

`bonyad_alavi_jihadi_center`

عنوان نمایشی:

«مرکز حرکت‌های مردمی و جهادی»

Block اصلی BEM:

`ba-jihadi-center`

این ویجت سکشن‌های زیر را رندر می‌کند:

- Hero
- Stats Panel
- معرفی مرکز و System Cards
- اخبار مرکز
- چندرسانه‌ای
- همراهان مرکز
- پرسش‌های متداول

Header و Footer نمونه HTML وارد ویجت نشده‌اند تا صفحه از Header/Footer اصلی سایت استفاده کند.

### ۴. Query Builder مشترک اخبار و چندرسانه‌ای

کلاس `BA_Content_Query_Service` اضافه شد تا منطق Query بین اخبار و چندرسانه‌ای تکرار نشود.

کنترل‌های هر Query:

- انتخاب یک یا چند Post Type عمومی
- تعداد نمایش
- انتخاب دسته‌بندی
- انتخاب برچسب
- انتخاب نویسنده
- Include بر اساس ID
- Exclude بر اساس ID
- Order By
- Order
- Offset
- Ignore Sticky Posts
- تاریخ شروع
- تاریخ پایان

در اخبار، اولین نتیجه Query به‌عنوان خبر شاخص و نتایج بعدی به‌صورت لیست کناری نمایش داده می‌شوند.

در چندرسانه‌ای، اولین نتیجه به‌صورت آیتم شاخص و نتایج بعدی در کارت‌های کوچک نمایش داده می‌شوند. Post Type به نوع خاصی قفل نشده است.

یک فیلد اختیاری `media_duration_meta_key` نیز در Elementor وجود دارد تا در صورت وجود متای مدت ویدیو در CPT انتخابی، مدت زمان بدون تغییر کد نمایش داده شود.

### ۵. لینک «مشاهده همه»

در اخبار و چندرسانه‌ای، لینک «مشاهده همه» فقط وقتی Render می‌شود که URL معتبر در Elementor وارد شده باشد.

### ۶. همراهان مرکز

در Elementor هر Partner دارای Switcher انحصاری است:

- حالت تصویر: فقط Media Image قابل انتخاب است.
- حالت SVG/Icon: فقط Icon Control Elementor قابل انتخاب است.

عنوان اختیاری است. لینک اختیاری است. اگر رسانه و عنوان هر دو خالی باشند، آیتم Render نمی‌شود؛ URL به‌تنهایی باعث ساخت باکس خالی نمی‌شود.

در داشبورد نیز همین قرارداد با Switcher «تصویر / SVG» و Media Library پیاده‌سازی شده است.

### ۷. استایل‌های Elementor

برای ویجت کنترل‌های گسترده Style اضافه شده‌اند، از جمله:

- عرض Container و پالت اصلی رنگ
- ارتفاع، Overlay، موقعیت تصویر، Typography و دکمه Hero
- Margin پنل آمار، Background، Radius، Shadow، Typography و Padding
- Background و Padding معرفی مرکز
- تعداد ستون Responsive، Gap، Border، Shadow، Radius، Min Height و Hover کارت‌های مرکز
- اندازه و Background آیکون کارت‌ها
- Typography و رنگ عنوان‌ها و متن‌ها
- Padding و Background اخبار
- ارتفاع خبر شاخص، Radius، اندازه تصویر لیست و Typography اخبار
- Padding و Background چندرسانه‌ای
- ارتفاع آیتم شاخص، Radius، رنگ Play Icon و Typography
- ستون‌ها، Gap، ارتفاع، Border، Radius و اندازه لوگوی همراهان
- Background، Padding، Gap، Typography، رنگ سؤال/پاسخ، علامت و Separatorهای FAQ

### ۸. JavaScript ویجت

اسکریپت ویجت دو مسئولیت مستقل دارد:

- Count-up آمار با پشتیبانی از ارقام فارسی/عربی و `prefers-reduced-motion`.
- Accordion FAQ که فقط در Scope همان نمونه ویجت کار می‌کند.

## معماری

### Service Pattern

- `BA_Center_Settings_Service`: مقداردهی پیش‌فرض، خواندن، تشخیص داده معتبر و Sanitize تنظیمات مرکز.
- `BA_Content_Query_Service`: تبدیل کنترل‌های Query Elementor به `WP_Query`.

### مسئولیت‌های جدا

- `BA_Center_Settings_Tab`: فقط ثبت تب، UI داشبورد و Assetهای مدیریتی.
- `Bonyad_Alavi_Jihadi_Center_Widget`: کنترل‌های Elementor و Render صفحه.
- `ba-center-settings.js`: رفتار Media Picker و Repeater داشبورد.
- `bonyad-alavi-jihadi-center-widget.js`: رفتار فرانت ویجت.

## BEM و جلوگیری از تداخل

UI فرانت فقط زیر Block زیر تعریف شده است:

`ba-jihadi-center`

UI داشبورد نیز Block مستقل دارد:

`ba-center-settings`

هیچ Selector عمومی جدیدی برای کنترل UI صفحه به قالب اضافه نشده است.

## اصلاح نگهداری

enqueue تکراری `ba-participation-checkout` در `functions.php` که از نسخه `v0.1.0` در Handoff ثبت شده بود حذف شد. شرط و Handle هر دو تکراری بودند و حذف نسخه دوم تغییری در خروجی مورد انتظار Checkout ایجاد نمی‌کند.

## تست‌های انجام‌شده

- اجرای `php -l` روی تمام فایل‌های PHP قالب.
- اجرای `node --check` روی تمام JavaScriptهای قالب.
- بررسی نام‌گذاری CSS جدید برای باقی‌ماندن در Scopeهای BEM.
- بررسی وجود Assetهای Hero و فایل‌های ثبت‌شده در Bootstrap.
- بررسی سلامت ZIP کامل و Patch با `unzip -t`.

## محدودیت تست

در محیط فعلی یک نصب واقعی WordPress + Elementor + دیتابیس محتوایی در دسترس نیست؛ بنابراین تست نهایی Visual/Interaction داخل Elementor Editor و Frontend باید پس از نصب Patch روی محیط Staging انجام شود. Syntax و ساختار فایل‌ها بررسی شده‌اند.
