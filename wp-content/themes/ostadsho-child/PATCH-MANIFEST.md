# Patch Manifest — ostadsho-child v0.5.8

## مبدا و مقصد

- مبدا: `v0.5.7`
- مقصد: `v0.5.8`
- نوع نسخه: PATCH

## هدف

یکدست‌کردن ابعاد تصاویر سکشن اخبار/مقالات و چندرسانه‌ای با نسبت تصویر مشخص و قابل تنظیم در Elementor، با کنترل مستقل برای آیتم شاخص و سایر آیتم‌ها.

## فایل‌های داخل Patch

### `inc/elementor/widgets/class-bonyad-alavi-jihadi-center-widget.php`

دلیل حضور در Patch:

- افزودن کنترل ریسپانسیو مستقل نسبت تصویر خبر/مقاله شاخص.
- افزودن کنترل ریسپانسیو مستقل نسبت تصویر سایر اخبار/مقالات.
- افزودن کنترل ریسپانسیو مستقل نسبت تصویر آیتم شاخص چندرسانه‌ای.
- افزودن کنترل ریسپانسیو مستقل نسبت تصویر سایر آیتم‌های چندرسانه‌ای.
- حذف کنترل‌های قدیمی ارتفاع ثابت آیتم شاخص که با `aspect-ratio` تداخل داشتند.
- افزودن Helper مشترک `register_image_aspect_ratio_control()` برای جلوگیری از تکرار تعریف گزینه‌ها و selectorها.

### `assets/css/bonyad-alavi-jihadi-center-widget.css`

دلیل حضور در Patch:

- افزودن نسبت پیش‌فرض `3:2` برای آیتم‌های شاخص اخبار و چندرسانه‌ای.
- افزودن نسبت پیش‌فرض `3:2` برای تصاویر لیست اخبار.
- افزودن نسبت پیش‌فرض `6:5` برای تصاویر کوچک چندرسانه‌ای.
- حذف `min-height` و `height`های ثابت قبلی که باعث اختلاف ابعاد در Breakpointهای مختلف می‌شدند.
- حفظ `object-fit: cover` برای پرشدن یکنواخت قاب تصویر.

### `docs/handoff.md`

دلیل حضور در Patch:

- ثبت قرارداد نسبت تصویر برای تصاویر اخبار/مقالات و چندرسانه‌ای.

- افزودن نسخه `v0.5.8` به تاریخچه پروژه.

Migration داده لازم نیست. کنترل‌های قدیمی ارتفاع آیتم شاخص دیگر CSS تولید نمی‌کنند و نسبت تصویر جدید مبنای اندازه قاب رسانه است.
